# GPS 1,000 人联合身体线索实验

每组使用归档中的同一批 1,000 个 Gallup ID。每次访谈按原协议回答 20 道题。题目生成、英文措辞、EUR 金额和 Luna 请求参数与归档一致。风险和耐心题保留自适应分支，后续题目金额由该组前序作答决定。

| 组 | 睡眠和步数 |
|---|---|
| 5 联合平均 | 7 小时（外部睡眠均值约 7.006 小时，按原数据粒度取整）、4,961 步（之前 100 人实验使用的总体均值） |
| 6 联合五档 | 复用学弟冻结的分配。睡眠 5、6、7、8、9 小时，步数 1,879、3,279、4,727、6,715、10,955。每项各档 200 人，25 个交叉格各 40 人。五档是归档参考分布的百分位点。 |
| 7 逐人联合 | 复用千人包中已经冻结的 sleep_draw 和 steps_draw，每人一对。睡眠按总体频数抽样，步数从按国家和性别分位点拟合并加权的混合对数正态分布抽样。两项分别抽样后按 ID 固定。原 100 人试跑的人口分层睡眠原始数据未随文件夹提供。GPS 中这 1,000 人的身体状态为模拟赋值。 |

`assignments.csv` 有每位参与者三组的数值。`prompts.jsonl` 有三组首题完整提示。已有 baseline、睡眠五档和步数五档从归档读取。

## 运行和续跑

在项目根目录用装有 pandas 和 numpy 的 Python 运行 `python GPS1000_joint/run.py run`。使用实验文件中配置的 Luna API，支持用环境变量 HKUST_API_KEY 覆盖凭据。当前 runner 复用原 100 人脚本的 curl 传输。中断后用同一命令续跑，已通过校验的答案会跳过。

`python GPS1000_joint/run.py check` 可离线验证人员、提示与归档设置。`python GPS1000_joint/run.py analyze` 可随时刷新报告。每个新组须有 1,000 套完整访谈才会进入比较。完整运行结束会自动生成报告。

## 两个问题

1. 身体信息如何改变 AI 作答。用同一参与者相对无身体线索 baseline 的原始回答变化、变化比例与变化幅度。阶梯题比较最终档位。
2. 哪个 prompt 最接近真人。按六个偏好等权平均的 GPS 个体 MSE 排序，同时报告分偏好、国家层级和相对 baseline 的配对 MSE 差。配对 bootstrap 的区间以本次观测作答和固定计分为条件。

归档 baseline 和新组调用在不同批次。观测差异也可能包含生成波动。每人每组只有一次访谈。七组中的真人 GPS 数据是比较参照。
